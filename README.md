中3総復習・高校入試対策用の社会書答式アプリです。

## 歴史・知識定着シート
1. 歴史 →「知識定着シート」
2. A版／B版を選ぶ
3. 時代を選ぶ
4. 表内の①②…を選び、右側の手書き欄へ回答
5. 「答えを見る」で表内に赤字の正答を表示
6. ○／△／×で自己採点し、表の最後に×だけ再挑戦可能

## 通常問題の学習の流れ
1. 分野・単元を選択
2. 手書き欄に自分で答える
3. 「答えを確認」で正答・別解・学習ポイントを表示
4. ○（できた）／△（迷った）／×（書けなかった）で自己採点
5. 周回モードまたは要復習問題を反復

## 主な機能
- Apple Pencil／指で使える大きな手書き欄
- 一つ戻す／全消去
- 10・20・50問のセッション選択
- 一周するまで同じ問題を出さない周回モード
- △・×を対象にした間違い見直し
- 10問ごとのごほうび画像
- 進捗はブラウザのlocalStorageへ保存
- 公民の時点依存問題は基準時点を表示
